# Global Connect Solutions (GCS) – Enterprise Network Design

## Overview

This project demonstrates the design and implementation of a realistic enterprise network using **Cisco Packet Tracer**.

The network simulates a multinational company with **8 branch offices** connected through **4 regional routers**, providing reliable WAN connectivity, dynamic routing, and centralized network services.

The main objective was to build a scalable, fault-tolerant, and secure enterprise network capable of maintaining communication even when WAN links fail.

---

## Network Features

* Enterprise WAN design
* Full Mesh topology between regional routers
* Dynamic routing using **EIGRP**
* IPv4 addressing with **VLSM**
* DHCP for automatic IP allocation
* DNS server
* HTTP Web Server
* FTP Server
* Email Server (SMTP/POP3)
* Secure remote management using SSH
* Router security configuration
* WAN redundancy and failover testing
* End-to-end connectivity verification using Ping and Traceroute

---

## Network Topology

The enterprise consists of:

* 4 Regional Routers

  * North America
  * Europe
  * Middle East
  * Asia-Pacific

* 8 Branch Offices

  * Manama
  * Dubai
  * Tokyo
  * Sydney
  * London
  * Berlin
  * New York
  * Toronto

Each branch contains:

* Router
* Switch
* Server
* Client PC
